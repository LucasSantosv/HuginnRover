# Firmware

Organização prevista para o firmware. Ainda não há código fornecido neste repositório.

- `rover/`: firmware embarcado no robô.
- `controller/`: firmware do controle remoto.
- `common/`: protocolos, estruturas de mensagens e código realmente compartilhado.

Ao adicionar código, registre placa, variante, ambiente de compilação, bibliotecas e estado de validação. Não misture código experimental com uma versão comprovadamente funcional sem identificá-los.

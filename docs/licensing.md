# Licença e reutilização

O autor ainda não escolheu uma licença para o projeto. A visibilidade pública do repositório, por si só, não concede uma licença open source.

Antes de aceitar contribuições ou convidar reutilização, o autor deve escolher separadamente as licenças de firmware, documentação, esquemáticos e arquivos CAD, se forem diferentes. Nenhuma licença foi adicionada nesta etapa.
